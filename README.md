# SirusMusic
Вся музыка клиента в одном окне: поиск, фильтры, избранное 1177 треков, зашитых в клиент, - слушайте

Установка
1. Скачиваем архив SirusMusic.
2. Полностью закрываем клиент игры.
3. Распаковываем папку из архива в Interface\AddOns\.
4. Итоговый путь должен выглядеть так: Interface\AddOns\SirusMusic\.
5. Запускаем игру.
