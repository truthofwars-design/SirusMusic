# SirusMusic
Вся музыка клиента в одном окне: поиск, фильтры, избранное 1586 треков, зашитых в клиент, - слушайте

Установка
1. Скачиваем архив SirusMusic.
2. Полностью закрываем клиент игры.
3. Распаковываем папку из архива в Interface\AddOns\.
Если скачали через гитхаб, то переименовываем папку "SirusMusic-main" в "SirusMusic"
5. Итоговый путь должен выглядеть так: Interface\AddOns\SirusMusic\.
6. Запускаем игру.
